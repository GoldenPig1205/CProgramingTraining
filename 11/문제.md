## 문제 1. 구조체 포인터

다음 코드에서 포인터 `p`를 이용해 `student`의 `score`를 90으로 변경하려고 한다. 빈칸에 들어갈 코드로 알맞은 것은?

```c
struct Student {
    int score;
};

int main(void) {
    struct Student student = {80};
    struct Student *p = &student;

    __________;

    return 0;
}
```

- ① `p.score = 90`
- ② `*p.score = 90`
- ③ `p->score = 90`
- ④ `p = 90`

## 문제 2. 구조체 배열

다음 프로그램의 실행 결과는?

```c
#include <stdio.h>

struct Student {
    char name[20];
    int score;
};

int main(void) {
    struct Student students[3] = {
        {"Kim", 90},
        {"Lee", 80},
        {"Park", 70}
    };

    printf("%d\n", students[1].score);

    return 0;
}
```

- ① `90`
- ② `80`
- ③ `70`
- ④ `3`

## 문제 3. 구조체를 함수에 전달하기

다음 프로그램의 실행 결과는?

```c
#include <stdio.h>

struct Person {
    int age;
};

void updateAge(struct Person p) {
    p.age = 22;
}

int main(void) {
    struct Person person = {25};

    updateAge(person);
    printf("%d\n", person.age);

    return 0;
}
```

- ① `25`
- ② `22`
- ③ `0`
- ④ 컴파일 오류가 발생한다.

## 문제 4. 공용체

다음과 같이 선언된 공용체에 대한 설명으로 옳은 것은?

```c
union Data {
    int number;
    float value;
};
```

- ① 공용체를 선언할 때는 `union` 대신 `struct`를 사용해야 한다.
- ② 공용체의 멤버는 모두 같은 자료형이어야 한다.
- ③ 각 멤버는 서로 다른 메모리 공간을 사용하므로 각각의 값을 동시에 보관할 수 있다.
- ④ 멤버들이 같은 메모리 공간을 공유하므로 한 멤버에 값을 저장하면 다른 멤버에 저장했던 값이 덮어써질 수 있다.

## 문제 5. 열거형

다음 프로그램의 실행 결과는?

```c
#include <stdio.h>

enum TrafficLight {
    Red,
    Yellow,
    Green
};

int main(void) {
    printf("%d %d %d\n", Red, Yellow, Green);

    return 0;
}
```

- ① `1 2 3`
- ② `0 0 0`
- ③ `0 1 2`
- ④ `0 1 1`
